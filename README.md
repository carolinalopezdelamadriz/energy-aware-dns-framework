# Energy-Aware DNS Framework

This repository contains the implementation of a framework designed to measure the protocol overhead of encrypted DNS (DoH, DoQ) and quantify its associated digital carbon footprint.

## Objectives

- Measure DNS protocol overhead
- Capture full web browsing traffic
- Convert traffic volume into energy consumption
- Estimate associated CO₂ emissions
